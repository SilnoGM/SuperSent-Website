macOS 与 Windows 本地内容工具

SuperSent一条内容，完整发送。

把常用文本、图片、文件、变量模板和组合内容保存在本机。macOS 按下 ⌘⇧Space， Windows 按下 Ctrl+Shift+Space，搜索后可直接复制、自动粘贴，或通过全引导式浮窗逐项预览并确认发送。

01 / 更少重复

不再把一组说明、图片和视频拆成三次寻找。

SuperSent 1.3.0 既能管理单条文本、图片、文件和变量模板，也能把需要连续发送的多种内容保存为一个有序条目。从创建、组织、搜索到发送，所有能力都在本机内容库中完成。本次新增 Windows x64 版本；两个系统使用各自独立的数据目录与更新通道。

02 / 完整功能目录

SuperSent 1.3.0

从保存第一条内容，到安全完成一次粘贴。

以下功能均来自当前正式版实现与自动化测试，不包含路线图或未发布能力。每项说明同时标明实际交互与安全边界。

A / CREATE

创建与内容类型

五种条目类型，共用标题、归属和检索能力。

纯文本与链接

保存普通文字、多段说明和 URL；链接按完整纯文本参与搜索、复制与粘贴，不转换成独立内容类型。

图片内容

导入图片到受管资源目录，在主窗口和搜索面板预览，并以系统图片格式写入剪贴板。

文件与视频

保存普通文件；常见视频仍属于文件内容，但会被识别并在主窗口、搜索面板中直接播放。

变量模板

使用 {变量名:提示文字} 定义动态字段；发送前按出现顺序填写，重复变量只询问一次。

组合内容

在一个条目中添加文字、图片和视频块，支持删除、拖动排序和保存前整体预览；全部内容块事务化保存。

导入与保存前重命名

图片、视频和文件先进入临时区，可在入库前改名；扩展名保持不变，同名冲突会提示且绝不覆盖。

B / ORGANIZE

组织与内容管理

从条目字段到分类树，持续保持资料库可维护。

完整条目字段

每条内容都可设置标题、类型、分类、分组、标签和别名；组合内容沿用同一套元数据。

新建、编辑与删除

主窗口直接创建和修改条目；删除前确认，并在数据库操作成功后才清理对应受管资源。

分类管理

创建分类并查看条目数量；删除分类时保留其中条目，只清空分类和分组归属，避免误删内容。

分类内分组

分组支持新建、重命名、上移、下移和删除；只有空分组可删除，同分类内不允许重名。

全部、高频与未分组视图

侧栏显示全部内容、高频常用、分类、真实分组和计算得到的“未分组”，每个节点同步展示数量。

自动继承当前位置

从分类、分组或未分组节点新建条目时，编辑器自动带入对应归属，并拒绝跨分类的无效分组。

主窗口筛选与排序

条目列表可按标题或标签即时筛选，并按最近使用时间或最近编辑时间排列。

受管资源安全清理

资源按图片、视频、文档、压缩包和音频等目录整理；共享资源、外部文件、符号链接和越界路径不会被误删。

C / FIND

搜索与预览

不离开当前应用，用键盘找到并确认目标内容。

全局快捷键

在任意应用按 ⌘⇧Space 打开悬浮搜索面板；注册快捷键本身不需要辅助功能权限。

多字段检索

同时搜索标题、正文、标签和别名；组合条目额外索引文字块与媒体文件名，不索引本地完整路径。

多关键词 AND 搜索

用空格输入多个关键词时，每个词都必须命中，可跨标题、正文和不同组合内容块共同匹配。

拼音与首字母

中文标题支持全拼和拼音首字母；组合文字内容也参与首字母检索，无需安装第三方词库。

相关度与常用度排序

精确别名、标题前缀、标签、正文等按相关度评分；分数相同时，使用次数更高的内容优先。

键盘与鼠标协同

使用 ↑↓ 切换结果、Enter 执行动作、⌥ Enter 仅复制、Esc 关闭。单击结果后可直接按 Enter，双击结果等同 Enter；搜索光标会停在查询词末尾。

分类路径提示

搜索结果显示“分类 / 分组”、仅分类或“无分类”，帮助区分同名内容，但路径不会改变搜索命中。

右侧完整预览

文本和模板显示可读正文，图片显示缩略图，视频提供播放控制，组合内容按真实顺序呈现全部块。

D / SEND

复制与发送

从单条快捷粘贴，到每块都由鼠标确认的组合流程。

普通条目自动粘贴

选择文本、图片、文件或已渲染模板后，SuperSent 写入系统剪贴板、恢复原目标应用并投递 ⌘V。

仅复制模式

按 ⌥ Enter 只写入剪贴板，不模拟粘贴；组合条目会提示改用全引导式发送，避免只复制第一块。

模板填写后发送

模板会先弹出变量填写框，生成最终纯文本后再按普通条目流程复制或粘贴。

逐块预览

组合内容启动后，在输入框附近展示当前文字、图片或视频预览、类型和总进度；视频不会自动播放。

粘贴、跳过、取消

每一块都通过鼠标按钮决定：粘贴当前项、跳到下一项，或立即取消整个流程。

浮窗自动定位

优先贴近当前输入框显示；空间不足时自动切换上下方，并限制在当前显示器可见区域内。

每次粘贴前复核目标

持续校验前台应用 PID、当前窗口与输入位置；目标应用或窗口发生变化时停止投递并提示返回。

网页输入框兼容模式

浏览器或自定义编辑器未公开可编辑节点时，使用当前聚焦窗口定位，并持续提示确认光标仍在输入框。

微信桌面端兼容

针对微信未公开输入框几何的情况使用安全窗口锚点，仍在每次粘贴前确认前台应用和目标窗口。

完成统计，不代替发送

结束后显示已粘贴与已跳过数量并记录一次使用；不会自动点击第三方应用的发送、发布或提交按钮。

E / SYSTEM

系统、隐私与更新

明确权限用途，发布与更新全程可验证。

后台常驻入口

macOS 菜单栏与 Windows 系统托盘均可打开内容管理窗口、手动“检查更新…”或退出应用。

辅助功能权限边界

全局搜索无需授权 macOS 辅助功能；只有定位输入框和向其他应用投递 ⌘V 时需要该权限。Windows 使用系统热键与剪贴板能力。

数据库与资源保存在本机

macOS 数据位于 Application Support/SuperSent；Windows 首次启动时由用户选择数据目录。两个平台不会读取、关联或迁移彼此数据。

无需账户与追踪

不要求注册，不提供云同步，不上传内容库、剪贴板内容或用户文件，也不使用分析和广告追踪服务。

自动与手动检查更新

启动后静默检查一次，持续运行时每四小时检查本平台更新源；后台入口仍可随时手动检查。

发现新版才提示

没有新版本时不打断操作；不会后台自动下载、安装或退出，最终更新始终由用户确认。

更新保留全部内容

平台更新器只替换程序文件，分类、分组、条目、数据库和托管资源继续保留。

分平台分发与更新校验

macOS 应用和 DMG 使用 Apple Developer ID 签名并通过公证；Windows 当前为未签名安装包，使用独立的 win-x64 更新源。

当前系统支持

macOS 版本要求 macOS 13 Ventura 或更高版本的 Apple Silicon Mac；Windows 版本要求 Windows 10 20H2 或更高版本的 x64 系统。

主要功能界面实景

每一项功能，都能在真实窗口中找到对应位置。

02 / 组合内容

文字、图片、视频，按实际发送顺序放进一个条目。

在同一个编辑器中添加多个内容块，并通过拖动调整次序。保存前即可同时检查编辑区与正文预览，避免遗漏附件或打乱说明顺序。

文字 图片 视频

每个组合条目都保留原有分类、分组、标签与搜索能力，不需要另建一套资料库。

03 / 全引导式发送

每一项都先预览，再决定是否粘贴。

启动后，输入框附近会出现不抢焦点的浮窗。文字、图片与视频依次进入确认流程，进度始终可见，并提供粘贴、跳过、取消三个鼠标按钮。

  • 粘贴将当前项写入目标输入框
  • 跳过保留顺序并转到下一项
  • 取消随时结束本次发送流程

已完成微信桌面端与网页输入框兼容验证；当网站不公开输入框定位时，可在确认光标后安全粘贴。

04 / 分类分组

一个分类之下，继续按用途整理。

同一类业务内容不必再挤在一张列表里。例如“测试设备”可以继续拆分为安装、教程、效果展示、参数信息，条目归属一眼可见。

测试设备
安装 教程 效果展示 参数信息

可新建、重命名、排序和删除空分组；从分组节点新增内容时，会自动继承对应分类和分组。

05 / 全局搜索

一个快捷键，直接抵达完整组合。

搜索标题、正文、标签、别名与拼音首字母。结果随输入即时更新，右侧按次序预览组合中的文字、图片和视频，再按 Enter 启动全引导式发送。

  • ↑↓切换搜索结果
  • Enter启动全引导式发送
  • 双击执行鼠标命中的结果
  • ⌥ Enter仅复制到剪贴板

06 / 内容管理

分类、分组、标签和别名，让资料库持续可用。

文本、图片、视频、普通文件与变量模板共用一套管理方式。导入资源会按图片、视频、文档、压缩包、音频等类型整理，查找和维护都更清楚。

删除条目时，只会清理受管目录内且不再被其他条目引用的资源，外部文件与共享资源保持不变。

文本 图片 视频 文件 模板

07 / 文件工作流

导入前先把文件名整理好。

添加图片、视频或普通文件时，可以在保存前重命名。扩展名始终保留；如果名称冲突，会直接提示且不会覆盖已有文件。

视频在主窗口与搜索面板中均可直接播放，并在预览离开后自动暂停。

08 / 变量模板

固定结构保留下来，变化内容发送前再填写。

用 {变量名:提示文字} 定义动态字段。选择模板后，SuperSent 会依次收集变量并生成最终内容。

开始使用

从安装到第一次组合发送，只需要三个动作。

  1. 01

    安装本平台版本

    macOS 打开 DMG 并拖到 Applications；Windows 可运行 Setup，或解压 Portable 后启动。

  2. 02

    建立组合内容

    按需建立分类与分组，在一个条目中依次添加文字、图片和视频并保存。

  3. 03

    按下快捷键

    在目标应用中，macOS 按 ⌘⇧Space，Windows 按 Ctrl+Shift+Space；搜索后按 Enter，再通过浮窗逐项确认粘贴。

隐私与权限

内容库属于这台设备。

SuperSent 1.3.0 无需账户，不提供云同步，也不使用分析或追踪服务。macOS 数据保存在 Application Support；Windows 数据保存在用户首次启动时选择的目录。

两个平台的数据彼此独立，不读取、关联或迁移。macOS 只有向其他应用自动发送 ⌘V 时需要辅助功能授权；未授权时仍会复制到剪贴板。
