01 / 更少重复

不再重新寻找、复制和整理同一份内容。

SuperSent 把常用内容变成一个随时可搜索的本地资料库。无需切换窗口翻找历史消息，也不必把临时文本散落在多个文档里。

v1.1.0 核心工作流

先用分类分组建立层级，再从同一条路径搜索和发送。

02 / 分类分组

一个分类之下，继续按用途整理。

同一类业务内容不必再挤在一张列表里。例如“焚烧炉”可以继续拆分为安装、教程、效果展示、参数信息，条目归属一眼可见。

焚烧炉
安装 教程 效果展示 参数信息

可新建、重命名、排序和删除空分组；从分组节点新增内容时，会自动继承对应分类和分组。

03 / 全局搜索

一个快捷键，直接抵达要发送的内容。

搜索标题、正文、标签、别名与拼音首字母。结果随输入即时更新，右侧同步展示“分类 / 分组”路径与完整内容，减少发送前的不确定。

  • ↑↓切换搜索结果
  • Enter复制并粘贴
  • ⌥ Enter仅复制到剪贴板

04 / 内容管理

分类、分组、标签和别名，让资料库持续可用。

文本、图片、视频、普通文件与变量模板共用一套管理方式。导入资源会按图片、视频、文档、压缩包、音频等类型整理，查找和维护都更清楚。

删除条目时，只会清理受管目录内且不再被其他条目引用的资源，外部文件与共享资源保持不变。

文本 图片 视频 文件 模板

05 / 文件工作流

导入前先把文件名整理好。

添加图片、视频或普通文件时，可以在保存前重命名。扩展名始终保留；如果名称冲突，会直接提示且不会覆盖已有文件。

视频在主窗口与搜索面板中均可直接播放，并在预览离开后自动暂停。

06 / 变量模板

固定结构保留下来，变化内容发送前再填写。

用 {变量名:提示文字} 定义动态字段。选择模板后，SuperSent 会依次收集变量并生成最终内容。

开始使用

从安装到第一次发送，只需要三个动作。

  1. 01

    拖入应用程序

    打开 DMG，将 SuperSent 拖到 Applications；首次启动会直接显示内容管理主窗口。

  2. 02

    建立分类与分组

    从菜单栏打开管理窗口，添加分类，再按安装、教程等用途建立分组并保存常用内容。

  3. 03

    按下快捷键

    在目标应用中按 ⌘⇧Space，搜索后按 Enter 完成发送。

隐私与权限

内容库属于这台 Mac。

SuperSent 1.1.0 无需账户，不提供云同步，也不使用分析或追踪服务。数据库与导入资源保存在本机 Application Support 目录。

全局搜索快捷键不需要辅助功能权限。只有向其他应用自动发送 ⌘V 时需要授权；未授权时，内容仍会复制到剪贴板。
