01 / 更少重复

不再把一组说明、图片和视频拆成三次寻找。

SuperSent 1.2.1 把需要连续发送的多种内容保存为一个有序条目。从创建、搜索到发送，顺序与预览始终保持一致。

v1.2.1 核心工作流

组合一次，搜索一次，再由你逐项确认发送。

02 / 组合内容

文字、图片、视频，按实际发送顺序放进一个条目。

在同一个编辑器中添加多个内容块，并通过拖动调整次序。保存前即可同时检查编辑区与正文预览，避免遗漏附件或打乱说明顺序。

文字 图片 视频

每个组合条目都保留原有分类、分组、标签与搜索能力，不需要另建一套资料库。

03 / 全引导式发送

每一项都先预览，再决定是否粘贴。

启动后，输入框附近会出现不抢焦点的浮窗。文字、图片与视频依次进入确认流程，进度始终可见，并提供粘贴、跳过、取消三个鼠标按钮。

  • 粘贴将当前项写入目标输入框
  • 跳过保留顺序并转到下一项
  • 取消随时结束本次发送流程

已完成微信桌面端与网页输入框兼容验证；当网站不公开输入框定位时，可在确认光标后安全粘贴。

04 / 分类分组

一个分类之下，继续按用途整理。

同一类业务内容不必再挤在一张列表里。例如“测试设备”可以继续拆分为安装、教程、效果展示、参数信息，条目归属一眼可见。

测试设备
安装 教程 效果展示 参数信息

可新建、重命名、排序和删除空分组；从分组节点新增内容时，会自动继承对应分类和分组。

05 / 全局搜索

一个快捷键，直接抵达完整组合。

搜索标题、正文、标签、别名与拼音首字母。结果随输入即时更新，右侧按次序预览组合中的文字、图片和视频，再按 Enter 启动全引导式发送。

  • ↑↓切换搜索结果
  • Enter启动全引导式发送
  • ⌥ Enter仅复制到剪贴板

06 / 内容管理

分类、分组、标签和别名，让资料库持续可用。

文本、图片、视频、普通文件与变量模板共用一套管理方式。导入资源会按图片、视频、文档、压缩包、音频等类型整理，查找和维护都更清楚。

删除条目时，只会清理受管目录内且不再被其他条目引用的资源，外部文件与共享资源保持不变。

文本 图片 视频 文件 模板

07 / 文件工作流

导入前先把文件名整理好。

添加图片、视频或普通文件时，可以在保存前重命名。扩展名始终保留；如果名称冲突，会直接提示且不会覆盖已有文件。

视频在主窗口与搜索面板中均可直接播放，并在预览离开后自动暂停。

08 / 变量模板

固定结构保留下来，变化内容发送前再填写。

用 {变量名:提示文字} 定义动态字段。选择模板后，SuperSent 会依次收集变量并生成最终内容。

开始使用

从安装到第一次组合发送，只需要三个动作。

  1. 01

    拖入应用程序

    打开 DMG，将 SuperSent 拖到 Applications；首次启动会直接显示内容管理主窗口。

  2. 02

    建立组合内容

    按需建立分类与分组，在一个条目中依次添加文字、图片和视频并保存。

  3. 03

    按下快捷键

    在目标应用中按 ⌘⇧Space，搜索后按 Enter，再通过浮窗逐项确认粘贴。

隐私与权限

内容库属于这台 Mac。

SuperSent 1.2.1 无需账户，不提供云同步，也不使用分析或追踪服务。数据库与导入资源保存在本机 Application Support 目录。

全局搜索快捷键不需要辅助功能权限。只有向其他应用自动发送 ⌘V 时需要授权；未授权时，内容仍会复制到剪贴板。
