SuperSent 隐私说明

SuperSent 1.1.0 是一款本地运行的 macOS 内容工具。无需账户，不提供云同步，内容库不会由应用上传到 SuperSent 服务器。

概要

  • 无需账户，也不要求提供姓名、邮箱或电话号码。
  • 内容数据库和导入资源保存在当前 Mac。
  • 不使用分析或追踪服务，不植入广告。
  • 检查更新只获取版本信息和安装包，不会上传内容库。
  • 自动粘贴权限可以不授予，复制功能仍然可用。

本地存储

SuperSent 使用本地数据库保存分类、标题、正文、标签、别名、使用次数等内容。图片、视频和普通文件也会复制到当前用户的 Application Support 目录中，以便后续预览和发送。

本地数据目录 ~/Library/Application Support/SuperSent/

SuperSent 1.1.0 不提供云同步，不会在不同设备之间自动传输这些内容。

权限用途

辅助功能权限

仅用于在你选择“发送并粘贴”后，将目标应用恢复到前台并向该进程发送 ⌘V。全局搜索快捷键本身不依赖该权限。

系统剪贴板

用于写入你主动选择的文本、图片或文件。SuperSent 不会在后台持续读取剪贴板，也不会建立剪贴板历史记录。

文件选择

仅在你主动导入或替换图片、视频和文件时访问所选资源，并将副本保存到应用本地目录。

网络与追踪

SuperSent 1.1.0 不使用分析 SDK、广告 SDK、崩溃上报服务或行为追踪服务，也没有账户系统和远程内容接口。 当你手动选择“检查更新…”或允许自动检查时，应用会从 SuperSent 官网获取签名版本信息，并按需从 GitHub 下载签名安装包；此过程不会上传内容库、剪贴板内容或所选文件。

本官网同样不加载分析脚本、第三方字体或广告资源。点击下载和问题反馈链接时，浏览器会打开 GitHub，并受 GitHub 自身的服务条款与隐私政策约束。

用户控制

你可以在 SuperSent 管理窗口中编辑或删除内容。删除条目时，仅会清理应用受管目录内且未被其他条目引用的资源；外部文件和仍被引用的资源不会被删除。

如果不授予辅助功能权限，选择内容后仍会先写入剪贴板，你可以在目标应用中手动粘贴。

问题反馈

对隐私说明或应用行为有疑问，可以通过公开 Issues 提交问题。请勿在公开反馈中附带个人内容库、账号凭据或其他敏感信息。
