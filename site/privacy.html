SuperSent 隐私与架构

SuperSent 1.3.1 是一款本地运行的 macOS 与 Windows 内容工具。无需账户，不提供云同步，内容库不会由应用上传到 SuperSent 服务器。

概要

  • 无需账户，也不要求提供姓名、邮箱或电话号码。
  • 内容数据库和导入资源保存在当前设备。
  • 不使用分析或追踪服务，不植入广告。
  • 默认自动检查只获取签名版本信息，安装仍需你确认，不会上传内容库。
  • 自动粘贴权限可以不授予，复制功能仍然可用。

平台架构

SuperSent 的 macOS 与 Windows 应用共享产品规则和版本号，但分别使用原生客户端、独立数据目录和独立更新通道。两个平台不会读取、关联或迁移彼此的数据。

macOS

原生客户端与签名更新源

应用数据保存在当前 macOS 用户目录；自动更新仅读取 macOS 签名 appcast，并校验 Apple Developer ID、公证和 Sparkle 签名。

Windows

x64 客户端与独立更新源

首次启动时由用户选择数据目录；Windows 10 20H2+ x64 版本只读取自己的更新源，不读取 macOS 数据或 appcast。

本地存储

SuperSent 使用本地数据库保存分类、标题、正文、标签、别名、使用次数等内容。图片、视频和普通文件也会复制到本平台的数据目录中，以便后续预览和发送。

macOS 数据目录 ~/Library/Application Support/SuperSent/
Windows 数据目录 首次启动时由用户选择的目录
Windows 目录定位配置 %APPDATA%\SuperSent\storage-location.json

SuperSent 1.3.1 不提供云同步，不会在不同设备之间自动传输这些内容。macOS 与 Windows 数据彼此独立，应用不读取、关联或迁移另一平台的数据。

权限用途

macOS 辅助功能权限

仅用于在你选择“发送并粘贴”后，将目标应用恢复到前台并向该进程发送 ⌘V。全局搜索快捷键本身不依赖该权限。

Windows 系统能力

Windows 版本使用系统级全局热键、剪贴板和输入投递能力完成搜索与发送，不会因此扫描其他应用的数据目录。

系统剪贴板

用于写入你主动选择的文本、图片或文件。SuperSent 不会在后台持续读取剪贴板，也不会建立剪贴板历史记录。

文件选择

仅在你主动导入或替换图片、视频和文件时访问所选资源，并将副本保存到应用本地目录。

网络与追踪

SuperSent 1.3.1 不使用分析 SDK、广告 SDK、崩溃上报服务或行为追踪服务，也没有账户系统和远程内容接口。 应用默认在启动后静默检查本平台版本信息，并在运行期间每四小时检查一次；你也可以手动选择“检查更新…”。macOS 与 Windows 使用相互独立的更新源，只有发现本平台新版本时才显示提示。安装包仍需你确认后才会从 GitHub 下载和安装；此过程不会上传内容库、剪贴板内容或所选文件。

本官网同样不加载分析脚本、第三方字体或广告资源。点击下载和问题反馈链接时，浏览器会打开 GitHub，并受 GitHub 自身的服务条款与隐私政策约束。

发布与更新

macOS 签名与公证

macOS 应用和 DMG 使用 Apple Developer ID 签名并通过公证；Sparkle 更新包还会校验独立的 EdDSA 签名。

Windows 未签名状态

Windows 当前安装包未进行代码签名，系统可能显示 SmartScreen 确认提示；官网不会把它描述为已签名安装包。

更新不迁移用户数据

更新只替换当前平台的程序文件，分类、分组、条目、数据库和受管资源继续保留在原数据目录。

用户控制

你可以在 SuperSent 管理窗口中编辑或删除内容。删除条目时，仅会清理应用受管目录内且未被其他条目引用的资源；外部文件和仍被引用的资源不会被删除。

在 macOS 上，如果不授予辅助功能权限，选择内容后仍会先写入剪贴板，你可以在目标应用中手动粘贴。Windows 用户可以在首次启动时选择数据目录，并可通过该目录自行备份或迁移数据；应用不会自动访问 macOS 数据。

问题反馈

对隐私说明或应用行为有疑问，可以通过公开 Issues 提交问题。请勿在公开反馈中附带个人内容库、账号凭据或其他敏感信息。
