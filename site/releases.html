v1.3.3

2026 年 8 月 25 日 当前版本

WINDOWS INSTALLATION & BRANDING

安装目录与任务栏品牌显示修复

下载当前版本

Windows 恢复安装目录选择，并让运行中的任务栏与窗口标题栏显示 SuperSent 品牌图标；macOS 同步进行稳定性优化。

macOS

  • 软件优化并修复已知问题，保持内容库、搜索与发送流程稳定。
  • 继续使用 Apple Developer ID 签名、公证和 Sparkle 签名更新。

Windows

  • 修复运行时任务栏图标，主窗口标题栏与任务栏统一显示 SuperSent 品牌图标。
  • MSI 安装流程重新提供选择安装目录页面，可在安装前指定目标路径。
  • 保持 Windows 10 20H2 或更高版本的原生 x64 系统支持。
  • Windows 安装包当前未进行代码签名，系统仍可能显示 SmartScreen 提示。

v1.3.2

2026 年 8 月 24 日

STARTUP & UPDATE HISTORY

单实例启动与版本历史入口修复

Windows 再次启动时复用当前实例，不再重复注册全局快捷键；macOS 的版本历史记录改为打开官网完整时间线。

macOS

  • “检查更新”中的“版本历史记录”现在使用默认浏览器打开官网版本更新时间线。
  • 当前版本说明仍由签名 Sparkle feed 提供，新版本发现、下载与安装流程保持不变。
  • 继续使用 Apple Developer ID 签名、公证和 Sparkle 签名更新。

Windows

  • 软件已运行时，再次点击桌面快捷方式会复用当前单实例并恢复现有主窗口。
  • 第二个进程在数据目录、托盘和全局热键初始化前退出，不再创建第二套应用组件。
  • 不再弹出由重复注册 Ctrl+Shift+Space 导致的“快捷键已被占用”提示。
  • Windows 安装包当前未进行代码签名，系统仍可能显示 SmartScreen 提示。

v1.3.1

2026 年 8 月 23 日

POLISH & NATIVE FIXES

实机体验修复与安装能力完善

macOS 恢复标准文本编辑快捷键；Windows 修复品牌图标与媒体预览，并增加可选择安装位置的 MSI。两个平台同步优化滚动条。

macOS

  • 恢复所有文本输入框的 Command+A、复制、剪切与粘贴快捷键。
  • 补齐标准编辑菜单、撤销和重做响应。
  • 使用更窄、更圆滑的系统覆盖滚动条。
  • 继续使用 Apple Developer ID 签名、公证和 Sparkle 签名更新。

Windows

  • 修复 Windows 品牌图标，主程序、标题栏与安装程序保持一致。
  • 图片、视频及组合媒体在搜索结果中直接显示预览。
  • 新增可选择安装位置的 MSI，官网以此作为推荐安装入口。
  • 媒体改为选中后加载，并使用窄圆角滚动条。

v1.3.0

2026 年 8 月 23 日 双平台起点

WINDOWS ARRIVES

首个 macOS 与 Windows 共用版本号的双平台版本

两个客户端共享内容管理与快捷搜索理念，同时保持原生实现、本地数据目录、构建资产和应用内更新源彼此独立。

macOS

  • 软件优化，既有内容库、全局搜索和组合内容发送行为保持不变。
  • 继续使用 Apple Developer ID 签名、公证与 Sparkle 更新链。

Windows

  • 首次支持 Windows 10 20H2 或更高版本的 x64 系统。
  • 提供文本、媒体、文件、变量模板、组合内容、分类与分组。
  • 支持 Ctrl+Shift+Space 全局搜索、托盘驻留、复制与粘贴。
  • 首次启动由用户选择独立数据目录，不读取、关联或迁移其他系统数据。
