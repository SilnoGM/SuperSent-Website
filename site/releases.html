v1.3.1

2026 年 8 月 23 日 当前版本

POLISH & NATIVE FIXES

实机体验修复与安装能力完善

下载当前版本

macOS 恢复标准文本编辑快捷键；Windows 修复品牌图标与媒体预览，并增加可选择安装位置的 MSI。两个平台同步优化滚动条。

macOS

  • 恢复所有文本输入框的 Command+A、复制、剪切与粘贴快捷键。
  • 补齐标准编辑菜单、撤销和重做响应。
  • 使用更窄、更圆滑的系统覆盖滚动条。
  • 继续使用 Apple Developer ID 签名、公证和 Sparkle 签名更新。

Windows

  • 修复 Windows 品牌图标，主程序、标题栏与安装程序保持一致。
  • 图片、视频及组合媒体在搜索结果中直接显示预览。
  • 新增可选择安装位置的 MSI，官网以此作为推荐安装入口。
  • 媒体改为选中后加载，并使用窄圆角滚动条。

v1.3.0

2026 年 8 月 23 日 双平台起点

WINDOWS ARRIVES

首个 macOS 与 Windows 共用版本号的双平台版本

两个客户端共享内容管理与快捷搜索理念，同时保持原生实现、本地数据目录、构建资产和应用内更新源彼此独立。

macOS

  • 软件优化，既有内容库、全局搜索和组合内容发送行为保持不变。
  • 继续使用 Apple Developer ID 签名、公证与 Sparkle 更新链。

Windows

  • 首次支持 Windows 10 20H2 或更高版本的 x64 系统。
  • 提供文本、媒体、文件、变量模板、组合内容、分类与分组。
  • 支持 Ctrl+Shift+Space 全局搜索、托盘驻留、复制与粘贴。
  • 首次启动由用户选择独立数据目录，不读取、关联或迁移其他系统数据。

v1.2.3

2026 年 8 月 19 日 仅 macOS

FOCUS & EXECUTION

搜索结果鼠标操作与键盘执行修复

macOS

  • 单击结果后可以直接按 Enter 执行当前条目。
  • 双击结果等同 Enter，且不会误执行列表空白区域。
  • 搜索框恢复焦点时，光标停在查询词末尾，不再默认全选。
  • 中文及特殊字符查询继续输入时不会覆盖已有内容。

v1.2.2

2026 年 8 月 19 日 仅 macOS

COPY ONLY

修复 Option+Enter 仅复制快捷键

macOS

  • 普通内容通过 Option+Enter 写入剪贴板并关闭搜索面板。
  • 仅复制不请求辅助功能权限，也不会向原应用自动发送粘贴快捷键。
  • 纯文本、变量模板、图片和普通文件均使用一致的仅复制行为。

v1.2.1

2026 年 8 月 19 日 仅 macOS

UPDATE AWARENESS

默认自动检查签名更新

macOS

  • 启动后静默检查一次，持续运行时每四小时检查一次。
  • 只有发现新版本时才提示，不在后台自动下载、安装或退出。
  • 菜单栏中的“检查更新…”仍可随时手动使用。
  • 更新安装只替换应用程序，不修改内容库与受管资源。

v1.2.0

2026 年 8 月 19 日 仅 macOS

COMPOSE & GUIDE

组合内容与全引导式发送

macOS

  • 一个条目可按任意顺序组合文字、图片和视频内容块。
  • 内容块支持添加、删除、拖动排序与保存前整体预览。
  • 全引导式发送逐项提供预览、粘贴、跳过和取消。
  • 新增 SQLite v4 迁移，历史数据保持不变且写入失败完整回滚。

v1.1.0

2026 年 8 月 19 日 仅 macOS

CONTENT GROUPS

分类内增加可选分组层级

macOS

  • 分类侧栏支持展开分组，并显示分组条目数量。
  • 支持新建、重命名、排序和删除空分组。
  • 新建条目可继承当前分类与分组，搜索预览展示完整位置路径。
  • 新增 SQLite v3 迁移，历史条目默认保持未分组状态。

v1.0.2

2026 年 8 月 17 日 仅 macOS

UPDATES & ASSET SAFETY

应用内检查更新与受管资源保护

macOS

  • 菜单栏新增“应用内检查更新”，支持查看说明、下载安装并重新启动。
  • 更新包、更新源与说明使用 Sparkle 签名校验。
  • 仅在资源属于受管目录且没有其他引用时删除文件。
  • 启动时直接显示内容管理窗口，关闭窗口后继续驻留菜单栏。

EMPTY LIBRARY FIX

macOS

  • 显式区分欢迎、新建与编辑三种会话状态。
